# AIccount - 智能记账应用

> 一个基于Vue.js的智能记账应用，结合AI助手帮助用户轻松记录和管理个人财务。

## 项目特点

- **AI辅助记账**：通过聊天式界面，让AI助手帮你解析和记录收支信息
- **直观数据展示**：明细页面按日期分组展示所有收支记录
- **数据可视化**：图表页面提供多种图表展示收支分析和趋势
- **简洁易用**：简约现代的UI设计，三大功能区域清晰分离

## 功能模块

### 1. 明细页面
- 按月份浏览收支记录
- 月度收支统计和结余计算
- 按日期分组展示收支详情
- 支持不同分类的可视化展示

### 2. 图表页面
- 支出分析：饼图展示支出分类比例
- 收入分析：饼图展示收入来源占比
- 收支趋势：柱状图展示近期收支变化
- 详细的分类数据列表

### 3. 记账页面
- 类ChatGPT聊天界面
- 自然语言输入记账信息
- AI智能解析收支内容
- 便捷的确认和修改功能

## 技术栈

- **前端框架**：Vue.js 2.x
- **路由管理**：Vue Router
- **UI设计**：纯CSS实现，无第三方UI库
- **数据可视化**：自定义CSS图表（未来计划集成ECharts）
- **数据存储**：计划接入LocalStorage/IndexedDB
- **AI服务**：预留外部AI服务接口

## 项目结构

```
src/
├── App.vue              # 应用主组件
├── main.js              # 入口文件
├── components/          # 公共组件
│   └── common/          
│       └── TabBar.vue   # 底部导航栏
├── router/              # 路由配置
│   └── index.js         # 路由定义文件
└── views/               # 视图页面
    ├── Details.vue      # 明细页面
    ├── Chart.vue        # 图表页面 
    └── Record.vue       # 记账页面
```

## 安装和使用

```bash
# 安装依赖
npm install

# 开发环境运行（热重载）
npm run serve
# 或
npm run dev

# 生产环境构建
npm run build

# 运行测试
npm run test
```
