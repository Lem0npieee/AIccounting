# AI记账应用 - 前端测试执行指南

## 概述

本指南详细说明了如何执行AI记账应用的前端测试，包括测试环境配置、测试执行、结果分析等完整流程。

## 快速开始

确保已安装必要的依赖：


### 2. 测试命令概览

| 命令                         | 描述           | 使用场景               |
| ---------------------------- | -------------- | ---------------------- |
| `npm run test:unit`        | 运行单元测试   | 开发过程中测试单个组件 |
| `npm run test:integration` | 运行集成测试   | 测试组件间交互         |
| `npm run test:all`         | 运行所有测试   | 完整测试覆盖           |
| `npm run test:watch`       | 监听模式测试   | 开发时自动运行测试     |
| `npm run test:coverage`    | 生成覆盖率报告 | 代码质量检查           |
| `npm run test:ci`          | CI环境测试     | 持续集成部署           |

## 测试分类详解

### 1. 单元测试 (Unit Tests)

测试独立的组件功能，确保每个组件按预期工作。

**包含的测试文件：**

- `Details.spec.js` - 明细页面测试
- `Record.spec.js` - AI记账页面测试
- `Chart.spec.js` - 图表分析页面测试
- `TabBar.spec.js` - 底部导航栏测试

**执行命令：**

```powershell
npm run test:unit
```

**测试重点：**

- 组件渲染
- 数据绑定
- 用户交互
- 异常处理
- 响应式设计

### 2. 集成测试 (Integration Tests)

测试组件之间的交互和数据流传递。

**包含的测试文件：**

- `App.integration.spec.js` - 应用整体集成测试

**执行命令：**

```powershell
npm run test:integration
```

**测试重点：**

- 路由导航
- 数据共享
- 状态管理
- 用户流程
- 性能优化

## 🔧 测试环境配置

### Jest 配置文件

测试配置位于 `test/unit/jest.conf.js`，包含以下关键配置：

```javascript
// 测试匹配模式
testMatch: [
  '<rootDir>/test/unit/specs/**/*.spec.js',
  '<rootDir>/test/integration/**/*.spec.js'
]

// 覆盖率阈值
coverageThreshold: {
  global: {
    branches: 70,
    functions: 70,
    lines: 70,
    statements: 70
  }
}
```

### 测试环境设置

- **测试环境**: jsdom
- **Mock工具**: 自动mock localStorage, fetch, Chart.js等
- **Vue组件测试**: 使用@vue/test-utils
- **路由测试**: 集成vue-router测试

## 🐛 常见问题解决

### 1. 测试环境问题

**问题**: Jest配置错误

```bash
Error: Cannot find module '@vue/test-utils'
```

**解决方案**:

```powershell
npm install --save-dev @vue/test-utils vue-jest
```

### 2. 组件导入问题

**问题**: 组件路径解析错误

```bash
Error: Cannot resolve module '@/components/...'
```

**解决方案**: 检查jest.conf.js中的moduleNameMapper配置

### 3. 异步测试问题

**问题**: 异步操作测试不稳定

**解决方案**: 使用flush-promises或await $nextTick()

### 4. Mock问题

**问题**: 第三方库mock失败

**解决方案**: 在setupTests.js中添加对应的mock配置

```yaml

on: [push, pull_request]

  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v2
      - uses: actions/setup-node@v2
        with:
          node-version: '14'
      - run: npm install
      - run: npm run test:ci
```
